# Project Context Snapshot

## Project Overview

We are building a **Flashcard Study Web Application**.

The application allows users to:
- Create decks
- Add flashcards
- Persist study material
- Later implement structured study and prioritization logic

This project is being developed under an **Iterative Agile SDLC model** and will also support algorithmic analysis requirements.

---

## Planned Tech Stack

- Node.js
- Express
- TypeScript
- Database: TBD (SQLite or PostgreSQL likely)
- Minimal frontend (functional, not design-heavy)
